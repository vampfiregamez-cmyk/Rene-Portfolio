# René Developer Portfolio V1

## Build
- Replace the starter page with a single cinematic portfolio experience using semantic sections for Home, About, Projects, Skills, and Contact.
- Create a near-black, crimson, and warm-white design system with dramatic display typography, technical labels, halftone grain, diagonal framing, panel rules, and restrained burgundy depth.
- Build a full-viewport introduction featuring “RENÉ,” the line “I build things worth remembering,” and a large clearly labeled portrait slot that never substitutes a generated person.
- Add an asymmetric character-profile About section, grouped skills presentation with honest placeholders only, an editorial Projects area with a polished coming-soon state, multiple optional photography slots, and a concise contact ending.
- Add minimal desktop navigation and an accessible mobile menu, with section links that preserve the requested one-page presentation.

## Motion and interaction
- Add scroll-triggered text and image reveals, staggered timing, subtle parallax, animated link rules, image-slot movement, cursor-aware project framing, and polished button states.
- Respect reduced-motion preferences and avoid continuous or distracting animation.

## Technical details
- Use React components and the existing TanStack Start structure without additional dependencies.
- Define all colors, typography, shadows, textures, and motion centrally in the Tailwind v4 design system.
- Use semantic HTML, keyboard-accessible controls, visible focus states, safe touch targets, and layouts tuned separately for desktop, tablet, and mobile.
- Add complete page metadata for search and social sharing.
- Keep personal copy, links, photos, and future projects in simple data structures so they are easy to replace later.

## Validation
- Verify the live page at desktop and mobile sizes, including menu interaction, section navigation, missing-image behavior, overflow, focus states, and reduced-motion behavior.
