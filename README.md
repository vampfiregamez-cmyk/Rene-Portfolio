# Crimson Code Chronicle

Build a personal developer portfolio website for me from scratch.

Overall Creative Direction

I want the website to feel like a high-end anime/manga-inspired personal portfolio, not a generic developer template.

The visual identity should communicate:

Creativity

Technology

Chess/intelligence

Coding

Ambition

A slightly dark, mysterious, rebellious personality

Anime/manga aesthetics

Think modern anime opening + premium manga cover + futuristic developer portfolio.

Do NOT make it look like a childish anime fan website. The anime influence should come primarily through composition, typography, motion, graphic elements, framing, manga-inspired layouts, and visual language while still feeling professional enough to show potential clients or employers.

Color Palette

Use a strong, memorable color palette rather than generic blue/purple SaaS colors.

Base the palette around:

Deep black / near-black backgrounds

Rich crimson / blood red as a primary accent

Off-white / warm white typography

Small amounts of muted gray

Optional subtle dark burgundy gradients

Red should be used strategically for important UI elements, highlights, hover states, lines, icons, and typography—not everywhere.

The overall feeling should be dark, cinematic, intense, and stylish.

Avoid excessive neon.

Typography

Typography is extremely important.

Use bold, dramatic display typography inspired by manga/anime title cards and Japanese editorial design for major headings.

Large headings should have personality and visual impact.

Use a highly readable modern sans-serif for body text.

Create a strong contrast between:

Huge expressive display headings

Small technical metadata

Clean body text

Use typography as part of the visual composition rather than treating it as ordinary website text.

Hero Section

Create a visually striking full-screen hero section.

Include:

RENÉ

A short developer-oriented tagline beneath it, something along the lines of:

“I build things worth remembering.”

The exact copy can be refined later.

The hero should include a large dedicated area for my own photography/portrait imagery.

IMPORTANT:
Do not generate a fake person or AI portrait.
Create clearly defined image placeholders where I can later upload my own photos.

The portrait treatment can feel like a manga/anime character introduction:

Large cropped portrait

Dramatic framing

Red graphic accents

Slight image distortion or grain

Manga-style borders/panels

Layered typography

Subtle motion

Navigation

Create a clean navigation bar with sections such as:

HOME
ABOUT
PROJECTS
SKILLS
CONTACT

Keep navigation minimal and elegant.

On mobile, convert it into a polished responsive menu.

About Section

Create an editorial-style About section.

Use asymmetric layouts rather than simply centering everything.

Include room for:

Short biography

Interests

Current focus

Technologies

Personal philosophy

Make this section feel like a character profile page from a premium manga, but translated into a professional developer portfolio.

Projects Section

Create a visually interesting project showcase.

Initially, I may have few or no projects, so design the system to handle empty states gracefully.

Use large project cards with:

Project image/thumbnail

Project name

Short description

Technologies used

GitHub link

Live demo link

When projects are added later, the cards should animate smoothly into view.

The project layout should feel more like a manga panel / editorial gallery than a conventional three-column SaaS card grid.

Skills Section

Create a visually interesting skills section rather than a boring list.

Group technologies logically, for example:

Languages
Tools
Frameworks
Other

Use subtle animations and interactive hover states.

Do not exaggerate skill levels or add technologies that I haven't provided.

Photography / Personal Image Areas

Throughout the site, deliberately include several large visual areas where I can eventually place my own photography.

Images should feel integrated into the design rather than simply placed inside rectangular cards.

Use:

Cropped portraits

Overlapping images

Manga-panel framing

Large editorial compositions

Red graphic overlays

Subtle grain

Layered text

Make sure the layout still works beautifully if some images are missing.

Animation & Motion

Motion is a major part of the design.

Use smooth, sophisticated animations throughout the site.

Include:

Fade-in animations

Fade-out transitions

Slide-in sections

Text reveal animations

Image reveal animations

Smooth scrolling

Hover animations

Subtle parallax

Scroll-triggered animations

Page/section transitions

Animations should feel cinematic and intentional, not like everything is constantly bouncing around.

Use staggered animation timing for text and visual elements.

Keep animations performant and respect prefers-reduced-motion.

Manga / Anime Visual Details

Use subtle graphic elements inspired by manga and anime:

Speed-line motifs

Panel borders

Thin red rules

Japanese editorial-inspired composition

Halftone textures

Screen-tone patterns

Small Japanese-style typographic accents where appropriate

Dynamic diagonal shapes

Numbered section markers

Small technical labels

Dramatic framing

Do NOT randomly insert Japanese words just to make it look anime.

Everything should have a design purpose.

Interaction Design

Make the website feel responsive and alive.

Examples:

Images subtly zoom or shift on hover

Links have animated underline/highlight effects

Project cards respond to cursor movement

Sections reveal themselves as the user scrolls

Large headings can have subtle motion

Buttons have polished hover/press states

Keep everything smooth and restrained.

Responsive Design

The website must be fully responsive.

Desktop should take advantage of large typography and dramatic layouts.

Tablet should preserve the visual hierarchy.

Mobile should be intentionally redesigned rather than simply shrinking the desktop layout.

Pay special attention to:

Typography scaling

Image cropping

Navigation

Touch targets

Animation performance

Avoiding horizontal overflow

Technical Direction

Use a modern, maintainable frontend architecture.

Prioritize:

Fast loading

Semantic HTML

Accessibility

Responsive design

Clean component structure

Reusable components

Optimized images

SEO-friendly structure

Do not add unnecessary dependencies.

Keep the codebase easy for me to modify later because I will continuously add projects and content.

Important Constraint

This is Version 1 of my portfolio.

Do not overfill it with fake projects, fake testimonials, fake statistics, fake clients, or fabricated achievements.

The site should feel complete and impressive through its design and art direction, even if the Projects section initially contains a tasteful “Projects coming soon” state.

Build the foundation so I can easily add real projects later.

The final result should feel like:

“If an anime protagonist became a software developer and their portfolio was designed like a manga cover.”

But keep it professional enough that I could confidently send the website to a potential client.
